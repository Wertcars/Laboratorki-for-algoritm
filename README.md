# Algorithmic Languages Labs

This repository contains all laboratory works for the course **Algorithmic Languages**.
Each folder represents a separate lab assignment and includes its own implementation, description, and answers.

---

## Each lab folder contains:

```
lab_X/ 
│ 
├─ README.md # Description of the lab
├─ requirements.txt # Dependencies  
│ 
├─ src/ # Source code
│   └─ labX.py
│ 
└─ report/ 
    └─ answers.md # Answers to theoretical questions
```

## Description

The purpose of this repository is to:

- store all laboratory assignments in one place  
- provide structured and readable implementations  
- track progress throughout the course  

Each lab demonstrates core Python concepts and their practical usage through code examples and program output.

---

## How to Run Labs

Follow the instructions provided in the `README.md` file inside each lab folder.
